01 — LIST & MAP

補給の計画は、
「何km地点にあるか」で決まる。

地図に点が打ってあるだけでは、走る順番がわかりません。 このツールは、見つけたスポットをルートに射影して「スタートから何km」に直します。

距離順のリスト

PCの手前にコンビニがあるか、一目でわかる。

  • 各スポットに「ルートから何m」を表示。脇道に入る距離が見える
  • 種類のチップで表示を絞り込み（件数付き）
  • 営業時間（OpenStreetMapに登録がある場合）も併記
  • リストをタップすると地図がそこへ寄る

02 — FEATURES

ルート図を、
補給計画に変える。

主催者から届くのはGPXの線だけ。そこに「どこで何が買えるか」を足します。

01

ルートに沿って探す

ルートから一定距離（100m〜1km）の範囲だけを探します。

  • ルートを等間隔にサンプリングして周辺を検索し、結果を合成
  • 見つけた地点をルートに射影して「何km地点」「ルートから何m」を算出
  • 範囲外のスポットは除外されるので、市街地でも見通しがよい

02

PCと並べて読む

GPXのウェイポイント（PC・通過チェック・START/FINISH）を旗で表示。

  • リストではPC行が色付きで割り込む
  • 「PCの手前○kmに最後の補給」がその場で読める
  • 地図の旗をタップするとkm地点を表示

03

種類で絞る・GPXに出す

コンビニ／レストラン・食堂／ファストフード／カフェ／日帰り温泉・銭湯／スーパー。

  • チップで表示・非表示を切り替え（件数付き）
  • 表示中のスポットをウェイポイントGPXに書き出し
  • サイクルコンピュータやRide with GPSに取り込める

04

無駄な通信をしない

同じGPX・同じ設定なら、前回の結果をそのまま使います。

  • 検索結果は7日間ブラウザにキャッシュ
  • Google Places を使う場合の無料枠を守れる
  • 「再検索」でいつでも最新に

03 — HOW TO USE

GPXを置くだけ。

アカウントもインストールも要りません。ブラウザで開いて、 ファイルを1つ放り込むところから始まります。

用意するもの 主催者配布のGPX（トラック形式）。Ride with GPS などから書き出したものでも構いません。 ウェイポイントが入っていればPCとして表示します。
ファイルは外に出ません GPXの読み込みも距離の計算もブラウザの中だけ。外部に送るのは、 地図タイルとスポット検索のための緯度経度だけです。
スマホでも 画面の上半分が地図、下半分がリスト。出走前の宿でも、コンビニの軒先でも開けます。
STEP1「GPXを開く」か、ドラッグ＆ドロップ
STEP2自動で検索。数秒〜数十秒でリストが出る
STEP3チップで種類を絞り、リストをタップして地図で確認
STEP4「地図↗」でGoogleマップへ。必要ならGPXに書き出し

04 — TWO MODES

キーなしで始めて、
必要ならGoogleに切り替える。

地図とスポットのデータは2系統。既定はキー不要のOpenStreetMapで、 設定にGoogle Maps APIキーを入れると地図もデータもGoogleになります。

O

OpenStreetMapモード（既定）

準備なしで今すぐ使えます。地方のコンビニは概ね登録されており、ブルベの補給計画には十分です。

地図OpenStreetMap（Leaflet）
データOverpass API（OSM）
必要なものなし
営業時間OSMに登録があれば表示
G

Googleモード

Google Cloud のAPIキー（Maps JavaScript API と Places API (New) を有効化）を設定に入れるだけ。キーはブラウザにしか保存しません。

地図Google Maps
データGoogle Places API (New)
必要なものAPIキー（請求先登録が必要）
費用の目安200kmで約250回。無料枠内
営業時間・定休日は、出発前に必ず確認してください。 表示されるスポットは OpenStreetMap または Google のデータをそのまま使っており、 閉店・移転が反映されていないことがあります。深夜・早朝に通過する区間では、 「地図↗」から営業時間を確かめるか、24時間営業の店を前提に計画してください。

05 — FAQ

よくある質問

アップロードしたGPXは、どこかに送信されますか？

されません。GPXはブラウザの中だけで読み込んで処理します。 外部と通信するのは、地図タイルとスポット検索（Overpass API または Google Places）に 緯度経度を渡すときだけです。

Google の APIキーは必須ですか？

必須ではありません。既定の OpenStreetMap モードはキーなしで動きます。 Googleの地図やPlacesの情報を使いたいときだけ、設定にキーを入れてください。 キーはブラウザの localStorage に保存され、Google 以外には送信しません。

Googleモードの費用はどのくらいですか？

Places Nearby Search は、200kmのルートを「ルートから300m」で探すと約250回の呼び出しです。 月5,000回までの無料枠に収まる範囲ですが、「ルートからの距離」を狭くすると検索円が小さくなるぶん回数が増えます（100mなら約750回）。 Google Cloud 側で Places API (New) の1日あたりの上限を設定しておけば、超過して課金されることはありません。 同じGPX・同じ設定なら結果を7日間キャッシュして再検索しません。

店が抜けている・閉店した店が出る

OpenStreetMap モードでは、登録されていない店は出ません。Google モードは1地点あたり20件までしか返さないため、 繁華街では取りこぼすことがあります。どちらも閉店・移転が反映されていない場合があるので、 「地図↗」でGoogleマップを開いて確認してください。

ルート形式（rte）のGPXでも使えますか？

使えます。トラック（trkpt）が無い場合はルートポイント（rtept）を読みます。 点が粗いGPXだと、道から外れた場所を「ルート上」とみなすことがあります。

書き出したGPXは何に使えますか？

表示中のスポットをウェイポイントとして書き出します。サイクルコンピュータや Ride with GPS などに取り込むと、走行中に「○km地点 ローソン」として表示できます。
